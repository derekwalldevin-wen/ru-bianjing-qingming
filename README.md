# 入汴京 · 清明上河图空间游记

**[打开三维游览](https://derekwalldevin-wen.github.io/ru-bianjing-qingming/)** — 无须登录 ChatGPT 或 GitHub。

基于 Three.js 的古画空间演绎：自由漫游、四章故事导览、长卷八景、原画与艺术复原对照、昼暮光影、水面反射和空间环境音。

67 处已标注的原画屋舍主体与1座重建城门、229 位人物（含4位楼上静置人物）、5 艘船、24 处摊位、4 辆车。角色具有障碍避让、身体与道具间距、独立脚踝贴地。道路使用颜色、法线与粗糙度贴图。

正店复合屋群按原画可见关系补出七开间主楼、双翼房、平座栏杆、侧梯和招幌，并修正三处屋舍标注。楼上人物、尺寸和隐蔽结构属于场景演绎，当前侧梯不支持上楼行走。

城门邻里的两处屋舍增添专属山面木构、格栅、低侧檐与瓦垄；在「城门楼阙」选择「近看屋舍」可观察细部、阅读片段，并打开对应原画局部。细部和隐蔽结构仍为艺术补全，原始布局与碰撞保持。

城门至正店的16组既有屋舍按街侧与前后排关系重新登记进深，12处门前土路柔化连接主街；原画左右次序与屋顶坐标保留，距离为可游览尺度解释。车马场景改由街道侧取景，牛车保持可见。

远景采用三层连续三维青绿山脊，替代重复圆丘；沿河方向保留低谷，峰峦与鞍部交错，保留世界空间彩墨皴擦和昼暮变化。山脉是艺术背景，不是汴京真实地理复原；没有新增模型下载或渲染通道。

「城外郊野」的漫游入口朝向原有村舍，乡路采用柔边土色，并点缀87簇早春草和53颗小碎石；这些为环境演绎，保留原有屋舍、源树群和碰撞。水面整体离开镜头时省去不可见倒影的重复绘制，镜头内水面仍逐帧更新；效果依机位而异。

## 游览

- 拖动环绕，滚轮调整远近；点击八景切换地点。
- 漫游默认与可见的宋代旅人同行，可切换亲历视角；WASD / 方向键移动、拖动转向、Shift 快走、Esc 返回俯瞰；手机可用方向按钮。角色身份和动作是场景演绎。
- 右上角「分享」复制当前景点及昼暮链接；「显示设置」选择画质与减少动态。
- 设备无法运行 WebGL 时，仍可阅读八景图像档案。
- 基础模型先载入，近景木作与生活道具按地点补载；增强失败仍可游览并重试。
- 旅人具有轻微呼吸、起停侧摆和有限顾盼；持卷双臂/卷轴同步，鞋底独立贴地。衣袍上段变形随动作，减少动态时保持中性，设置/档案弹窗暂停动作。
- 可见旅人的袍身和袖筒由原控制网细化为连续衣褶，保持原比例、鞋底与身体外缘；群体人物继续共享原模型，无新增模型包。
- 减少动态时，完全静止且光照、人物、器物和镜头都未变化的倒影会复用；移动、换光和精修加载及时重绘。普通动态继续逐帧反射。
- 岸边早春草簇采用原创三维弯叶与细微叶尖摆动；减少动态或流畅画质时静止。土路使用原创多尺度材质与近水色差。草叶与微观土色为场景演绎。
- 在「汴河舟楫」岸边靠近松绳，可按 E 或点提示完成归拢绳头、回到绳圈盘好；完成后可选看河面、对照原画或继续漫游。此生活小事与器物为场景演绎。
- 「汴河舟楫」的「近看舟楫」可细看独立精修的船篷、缆绳与船板，新增船包按物件需要下载。
- 「沿街市井」的「近看商贩」提供一位可爱商贩的回望与轻招呼；面貌和动作为艺术演绎。流畅画质或减少动态时静候，动作复用已有模型。
- 「桥畔茶铺」的「近看檐下」可看浅坡瓦檐、木作桌凳和碗内壁；一处精修铺面按物件补载，保持其余街区的实例化与人群。器皿、布置和茶铺命名为演绎。
- 「草棚人家」的「近看草檐」可看厚草层、捆扎、篮的空隙和陶罐内壁；独立包按物件补载，原地面与街道人群保留。屋前器物与细部为演绎。

依据用户完整故博本画心重新组织城内铺面、城外屋舍、虹桥与郊野，撤去上一版265栋没有原画对应关系的网格房屋。新城门有矩形门道、收分台基、五开间楼身、平座与阶梯；增加城门和郊野两处入口。约1.24公里的艺术化运河和三层青绿远山保留。近景保持原画依据，远山借鉴《千里江山图》的石青、石绿色调；新增城门为程序化合批几何，不新增GLB包；67处标注不是穷尽全卷所有屋顶，也不是历史测绘，散点透视的三维进深与隐蔽结构仍为解释性补全。山林进一步采用原创彩墨材质：世界空间皴擦、墨色轮廓与点叶树丛，保留三维视差和昼暮变化；《三国志11》仅为视觉方向参考，不含其游戏资产。

## 本地开发

无需构建与 npm 依赖。安装 Node.js 后运行 `node serve.mjs`，打开 http://127.0.0.1:4187/ 。ES modules 必须通过 HTTP 加载。

`src/` 是完整应用源码；`assets/` 包含 GLB 模型、道路材质与参考图；`vendor/` 为本地依赖。
GitHub Pages 从 main 分支根目录发布。更新源文件并推送 main 即可重新部署。

卷首两处既有村舍补出厚草檐、散梢、山面木构、格窗与门槛；在「城外郊野」选择「近看村舍」并「细看」，可推开或合上主屋门扉。新增第9处观察与两条线索、对应未提亮原画局部。门窗分格、隐蔽背面和开合动作均为艺术补全；当前不支持进入室内。

卷首乡路外增加三条低缓土岸，结合原画水平土岸与疏林留白组织地表；具体高程和纵深为艺术补全。土坡纳入真实鞋底与镜头地面支撑，保留既有乡路、源屋舍/树根与篱栏地基。约5441个三角形、1个批次，没有新增模型下载；远地表在38..160米间连续减弱重复底色与法线颗粒，近处道路肌理保留；不代表整片郊野或历史地理已完整复原。

旅人接触岸绳时使用同源工作骨架：右手俯身拾起绳头、携绳回到圈旁、蹲身盘放；绳尾跟随实际掌心并与岸石接触。左手保留书卷，工作袖口有厚度与内衬；移动可中断尚未完成的动作，弹窗暂停，减少动态直接到持绳或完成状态。这些动作与器物为场景演绎，并非原画人物动作的史实复原。

寻找绳头与返回绳圈时，任务卡按实际观察方向提示方位及近似直线距离。盘好后会在本浏览器留下一条行旅记录，再次进入仍可看见整齐绳圈；「再试一次」可重玩，放弃重试会回到此前的完成状态。只有真正盘好才保存，阅读原画与中途持绳不算完成；浏览器不允许本地保存时仍可正常游玩。

基础船上的船家补有七片木板与双承木构成的工作铺板，已有精修甲板的船保持原甲板。船家在脚位固定的同时轻微调整重心、扶篙静候，近岸有人时有限顾盼；这不是完整推篙或水下接触模拟。开启减少动态后，船和人物停在当前地点及姿态，不再返回船只起点。新增铺板及人物动作为场景演绎，无新模型包下载。

## 界面美术

青绿长卷界面结合绢本题签、朱砂印章与宋画青绿色彩。先用 AI 生成 UI 概念稿，再以 HTML/CSS 实现真实控件。封面使用原画局部与项目 AI 生成的透明山峦，游览中心仍是 Three.js 三维场景。

## 来源与边界

这是一段依据《清明上河图》视觉资料创作的可游览街区，不是整卷逐栋测绘复原。建筑背面、尺寸、配色及街巷距离含艺术补全。
